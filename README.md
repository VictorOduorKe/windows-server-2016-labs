# Windows Server 2016 Administration Lab

## About This Project

This repository documents my hands-on learning journey with Windows Server 2016 using Oracle VirtualBox.

The purpose is to develop practical skills in Windows Server administration, networking, identity management, security, troubleshooting, and infrastructure management through structured lab exercises.

## Lab Environment

- **Server OS:** Windows Server 2016
- **Virtualization:** Oracle VirtualBox
- **Administration:** Server Manager, PowerShell, Command Prompt
- **Networking:** TCP/IP, DNS, DHCP, virtual network configuration
- **Documentation:** Markdown, screenshots, and configuration notes

## Learning Objectives

- [ ] Install and configure Windows Server
- [ ] Configure networking and troubleshoot connectivity
- [ ] Understand server roles and features
- [ ] Install Active Directory Domain Services
- [ ] Create and manage users and groups
- [ ] Configure DNS and DHCP
- [ ] Configure file sharing and permissions
- [ ] Apply Group Policy
- [ ] Implement basic server security
- [ ] Automate administration using PowerShell
- [ ] Monitor events and troubleshoot common issues

## Lab Documentation

Each lab includes its objectives, environment, implementation steps, verification results, screenshots where useful, and troubleshooting notes.

See the `labs/` directory for individual exercises.

## Progress

Labs are documented as I complete and verify them. An incomplete or untested exercise is not marked as completed.

## Disclaimer

This is a personal educational lab. All configurations and tests are performed in a controlled virtual environment.
